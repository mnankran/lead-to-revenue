# Data

**No data is committed to this repository.** Every query reads the public dataset directly in BigQuery.

## GA4 obfuscated sample ecommerce

- **Table:** `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*` (one table per day, 2020-11-01 to 2021-01-31)
- **Publisher:** Google, as a public demo of the GA4 BigQuery export. Description and terms:
  <https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset>
- **Obfuscation:** part of the values are replaced by placeholders such as `(data deleted)`, so findings describe the sample.
